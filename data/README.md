# CMAPSS FD001 Dataset

NASA Commercial Modular Aero-Propulsion System Simulation (CMAPSS), podskup FD001.

- `train_FD001.txt` - trening trajektorije (100 motora, run-to-failure)
- `test_FD001.txt` - test trajektorije (100 motora, prekinute prije otkaza)
- `RUL_FD001.txt` - referentne RUL vrijednosti za test skup

Izvor: NASA Prognostics Center of Excellence.
